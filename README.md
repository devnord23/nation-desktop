# Nation Team Chat: desktop releases

This repository only hosts **installers and update feeds** for the Nation Team Chat desktop app. The source code is private.

- **Download (Windows):** [latest installer](https://github.com/devnord23/nation-desktop/releases/latest/download/NationTeamChat-setup.exe), or pick a version under [Releases](https://github.com/devnord23/nation-desktop/releases).
- **Updates:** installed apps check this repository's releases (`latest.yml`) and update themselves.
- **Unsigned build:** Windows SmartScreen may show "unknown publisher". Choose **More info → Run anyway**.
